# Licenses

Licenses are verified on the `LICENSE` files of the module cache and audited with
`go-licenses`:

```
GOROOT=$(go env GOROOT) go-licenses check ./...
```

Project license: MIT (LICENSE).

Accepted dependency licenses: MIT, BSD, Apache-2.0, ISC. `GOROOT` must be set
explicitly, otherwise `go-licenses` fails on standard-library packages.

## Test-only images

`testdata/images/` holds the JPEG and PNG test images of Go's `image` package, copied
unmodified from the local Go 1.27.4 installation (`$GOROOT/src/image/testdata`). They are
used by tests only and are never embedded in the library or imported by library code. The
file list, source and SHA-256 are in `testdata/images/README.md` (checked by a test).

| Files | Licence | Text |
|---|---|---|
| `video-001.*`, `video-005.*` | BSD-3-Clause, The Go Authors | `testdata/images/LICENSE-Go` |

Crafted hostile and boundary images, and one image of each PNG variant, are generated by
`internal/testcorpus/images.go`; nothing is downloaded and no malware is stored.
